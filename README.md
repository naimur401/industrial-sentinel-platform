\# 🏭 Industrial Sentinel

No connection to real Aramco / SCADA / production network.

\- Frontend: Next.js, React, TypeScript, Tailwind, shadcn/ui

\- Backend: NestJS (modular monolith), Prisma

\- AI: Python, FastAPI, scikit-learn, XGBoost

\- DB: PostgreSQL + TimescaleDB

\- Queue: Redis + BullMQ
